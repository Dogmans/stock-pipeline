# Scripts

This directory contains supported launchers, diagnostics, and code examples:

- `run_offline_regressions.py`: Network-isolated project regression suite
- `start_visual_editor.ps1`: Local workflow editor launcher
- `diagnose_fmp_performance.py`: FMP timing diagnostic
- `powershell/`: PowerShell reference material and focused helpers
- `python/`: Python code examples

Run these scripts from the project root directory.
